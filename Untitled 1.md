**Job header & metadata**

1. As a user, I want to edit the job name, PO number/name, job type, and production type from the job detail panel, so that job metadata stays accurate.
2. As a user, I want to see the job's current status and last-modified info at a glance, so that I know its state without digging further.
3. As a user, I want to generate and view a print ticket (Ticket / Interior Board Sheet / All), so that I can produce physical/PDF paperwork for the job.
4. As a user, I want to link and edit a Trello Card ID on a job, so that production tracking stays synced with Trello.

**Job details (Production tab)**  
5. As a user, I want to add a job detail with General info (quantity, panels, sides, size, menu/insert size), so that I can define a new print component.  
6. As a user, I want to specify Paper info (size, type, weight, color, other) for a job detail, so that paper specs are recorded for production.  
7. As a user, I want to select Print Finishing options (lamination, UV coat, and operations like perf/drill/stitch/fold/die cut), so production knows what finishing work is required.  
8. As a user, I want to select Bindery Finishing options (decoration like emboss/deboss, and binding type like ring binder/screwposts), so bindery gets accurate specs.  
9. As a user, I want to add Interior Board details (insert sizes/quantities, board corners/tabs, special instructions), so interior board requirements are captured.  
10. As a user, I want to edit or delete an existing job detail, so I can correct mistakes or remove obsolete detail lines.  
11. As a user, I want validation to prevent saving a job detail without a description/quantity, so incomplete details can't be submitted.

**Shipping tab**  
12. As a user, I want to add a shipping address with carrier, account, method, attention, and notes, so shipments are routed correctly.  
13. As a user, I want to edit or delete an existing shipping address, so shipping info stays current.  
14. As a user, I want to select multiple shipping addresses via checkboxes, so I can perform bulk actions (worth confirming what the checkboxes actually enable).  
15. As a user, I want validation to prevent adding a shipping address with an invalid quantity, so shipping data stays clean.

**Notes & contacts**  
16. As a user, I want to add/view notes categorized by type (General, Billing, Shipping, Detail, Paper) and search them, so I can quickly find relevant context.  
17. As a user, I want to manage job contacts by role (Proofing, Invoicing, Shipping Notifications), so the right people are notified at the right stage.

**Billing & activity**  
18. As a user, I want to view billing details (PO info, billing notes, linked invoices), so I can confirm invoicing status without leaving the job page.  
19. As a user, I want to view a chronological activity log of status changes, so I can audit the job's production history.

**Navigation**  
20. As a user, I want to use breadcrumbs (Dashboard > Customer > Sub-account > Job) to navigate back up the hierarchy, so I can move between related records easily.
